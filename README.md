# Interest Simulator

A simple web tool to compare simple interest and compound interest over time.

## Features

- Calculate simple interest
- Calculate compound interest
- Compare the difference between the two approaches
- Runs directly in the browser
- No account required
- No server-side storage
- Static and easy to deploy on Cloudflare Pages

## Privacy

This tool runs locally in the user's browser.

The values entered by the user are not intentionally sent to external services, stored on a server, or logged by this project.
